# 오케이청소 공식 홈페이지

- 홈페이지: https://okclean-kr.github.io/
- 고객용 진입 주소: https://okclean-kr.github.io/app/
- 관리자 안내: https://okclean-kr.github.io/admin/

## 복원 범위

2026년 11월 9일 보관한 백업의 11월 3일 홈페이지 소스를 새 계정 `okclean-kr`에 맞춰 복원했습니다. 이 저장소에는 공개 홈페이지 파일만 포함합니다.

- 홈페이지, 서비스 소개 12개, 지역 소개 3개
- 시공 사례 53건과 청소 팁 5건
- 사례 사진 48개 로컬 복원; 2건은 기존 외부 이미지 주소 유지; 8건은 원래 사진 없음
- 견적 계산, 전화·문자·카카오톡 상담 연결
- 고객용 진입 경로와 기존 관리자 사이트 안내
- 새 주소에 맞춘 사이트맵, 공유 주소, 설치용 manifest 및 캐시 범위

## 2026-11-12 상담 동선 개선

첫 화면에서 실제 작업 사진과 사진 견적 문의를 안내합니다. 대표 작업 3건은 기존 블로그 기록과 로컬 사진을 연결했습니다. 예상 견적 계산기는 별도 영역에 두고, 가입·앱 설치·추천제품은 상담 흐름 뒤에 배치했습니다. 서비스 12개와 지역 3개 페이지에도 사진 상담 동선과 검색·공유 설명을 반영했습니다.

`cases.json`의 원본 58건은 보존합니다. `case-classification.json`에서 작업 기록과 청소 팁·공지·개인 기록을 구분하며, 분류 파일을 불러오지 못하면 확인된 대표 작업만 사례로 표시합니다. `featured-cases.json`에 기록한 날짜는 블로그 발행일이며 작업일을 의미하지 않습니다.

## 기능 상태

회원 신청은 `member-sync.js`의 기존 Firebase 저장 흐름을 사용합니다. 신규 저장 성공이 확인된 뒤 쿠폰을 표시하며, 친구 소개 자동 적립과 별개입니다. 이번 개선은 가격 설정과 회원 저장 구조를 바꾸지 않습니다. 기존 관리자 사이트는 `https://okclean-admin-app.web.app/admin/`입니다.

방문·견적·상담 버튼 측정과 `admin/analytics.html`을 연결했습니다. 2026-11-12 기존 Google 관리자 계정으로 운영 Firestore의 시험 저장 및 서버 재조회를 확인한 뒤 `analytics-config.js`를 `enabled: true`, `verified: true`로 활성화했습니다. 출처별·한국시간 날짜별 조회가 가능하며 시험 기록은 운영 집계에서 제외합니다. 전화·카톡 버튼 클릭 수는 실제 통화·문의·예약 수를 의미하지 않습니다.

개인정보처리방침에서 이 브라우저의 새 통계 수집을 끄거나 켤 수 있습니다. 방문·상담 통계에는 허용된 행동 분류와 서버 시각만 보내며, 추천제품 버튼 통계에도 동일한 선택을 적용합니다. 상세 수집 범위, 실제 연결 근거와 측정 한계는 [측정 연결 문서](ops/analytics-measurement.md)에 있습니다. 방문·상담 통계 `site_events`는 90일을 기준으로 보관하며, 기존 Google 관리자가 통계 페이지를 열 때 90일이 지난 자료를 최대 600건씩 정리합니다. 페이지 미접속·통신 오류·처리 상한이 있으면 더 보관될 수 있습니다. 추천제품 클릭 `product_clicks`에는 자동 삭제 기간을 설정하지 않았습니다. 구현·규칙 적용 상태는 [통계 보관기간 문서](ops/analytics-retention.md)에 기록합니다.

두 공식 블로그의 새 글은 매시간 17분 실행되는 [RSS 갱신 작업](ops/case-sync.md)으로 확인합니다. 기존 기록은 보존하고 새 글만 추가하며, 실제 작업 기록과 청소 팁을 구분합니다. 보관된 원본 소스, 백업 전체, 실제 고객정보, 인증 비밀정보는 이 공개 저장소에 넣지 않습니다.

## 게시 방식

GitHub Pages는 `main` 브랜치의 저장소 최상위 폴더(`/(root)`)를 게시합니다. `index.html`과 `.nojekyll`을 이 폴더에 둡니다. 복원 브랜치가 `main`에 반영되면 기존 Pages 배포가 시작됩니다.

## 검증

`tests/analytics.test.cjs` 24개와 `tests/analytics-maintenance.test.cjs`의 모듈·관리자 화면 검증 23개를 통과했습니다. 격리된 Firestore Emulator에서는 90일 삭제 조건 22개와 기존 생성·조회·회원·접수증·상품 권한 63개를 검증했습니다. 실제 서버 시험 저장·재조회와 보관기간 정리 기능의 운영 적용 상태는 별도로 구분합니다. JavaScript 구문, HTML 내부 참조와 앵커, 기존 가격·회원 설정 보존도 검사했습니다. 실제 전화·문자·카카오 메시지 전송이나 시험 회원가입은 수행하지 않았습니다.
