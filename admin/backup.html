고객 자료 암호화 백업

기존 Google 관리자만 서버 자료를 읽어 백업할 수 있습니다. 암호화 파일을 내려받아 보관하고, 같은 파일을 다시 읽어 확인할 수 있습니다.

로그인을 확인하고 있습니다.

백업 범위

회원 정보·쿠폰 접수증, 실제·시험 견적, 현장 사진, 상담·견적 이력과 해당 견적에 연결된 접수증·접수 제한 문서를 포함합니다.

통계·추천제품·인증 계정·부모와 연결되지 않은 문서·미등록 컬렉션은 포함하지 않습니다. 전체 Firebase DB의 동일 시점 백업은 아니며, 서버 부모 문서를 다시 읽어 내보내기 중 변경을 확인합니다. 최대 5,000문서·원문 20MB까지 처리하고 상한을 넘으면 파일을 만들지 않습니다.

이 도구는 서버 조회만 수행합니다. 운영 자료를 수정하거나 복원하는 기능은 없습니다. 백업 파일에는 개인정보가 암호화되어 있으므로 암호와 파일을 별도로 보관하세요. 암호를 분실하면 파일을 복호화할 수 없습니다. 보관 파일에도 기존 개인정보 보관·삭제 기준을 적용해 관리하세요.

1. 암호화 파일 준비

백업 파일에만 쓸 전용 암호를 직접 정해 입력하세요. 암호는 서버나 브라우저 저장소에 저장하지 않으며 작업 후 입력란에서 지웁니다.

암호를 입력하면 시작할 수 있습니다.

2. 보관한 파일 다시 확인

내려받은 암호화 파일과 같은 암호로 무결성·문서 수·사진·시각 형식을 확인합니다. 이 확인으로 운영 DB에 쓰거나 복원하지 않습니다.

파일과 암호를 입력해 주세요.
