# 오케이청소 개인정보 삭제·보존 운영안

## 기준
- 회원 기본정보: 탈퇴 요청 시 또는 마지막 이용 후 2년
- 상담 상태/관리 메모: 상담 종료 후 90일
- 법정 거래기록: 관련 법령의 보관기간 우선

## 삭제 대상
회원 삭제 시 동일 UID의 두 문서를 함께 처리한다.
- member_requests/{uid}
- member_receipts/{uid}

## 권한
- 일반 고객: 자기 receipt 단건 조회 외 삭제 불가
- 관리자 Google UID만 삭제 허용
- 관리자 UI에서 삭제 전 회원명/쿠폰코드 재확인
- 삭제는 두 문서를 batch delete로 한 번에 처리
- 실패 시 한쪽만 삭제된 것으로 표시하지 않고 재검증

## 관리자 UI 권장 흐름
1. 회원 상세에서 '개인정보 삭제' 선택
2. 1차 경고: 복구 불가 안내
3. 확인 입력: 회원 이름 또는 쿠폰번호
4. batch delete 실행
5. 두 문서 모두 미존재 확인 후 완료 표시

## 자동 보존 정리
- 무료 범위 우선: 자동 삭제 스케줄은 당장 켜지 않음
- 관리자 목록에 '90일 경과 상담' 필터를 추가해 월 1회 수동 정리 가능
- 향후 자동화 시 유료 기능/Cloud Functions가 필요한지 먼저 확인 후 별도 승인

## 현재 상태
- 운영 Firestore 규칙은 delete:false로 유지
- 실제 삭제 기능은 아직 미배포
- 이 문서는 구현 기준을 고정하기 위한 운영안
