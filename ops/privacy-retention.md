# 오케이청소 개인정보 삭제·보존 운영안

## 현재 운영 기준
- 회원이 삭제를 요청하면 관리자가 확인 후 개인정보를 삭제할 수 있다.
- 관리자 삭제는 동일 UID의 두 문서를 함께 삭제한다.
  - `member_requests/{uid}`
  - `member_receipts/{uid}`
- 관리자 삭제 권한은 등록된 Google 관리자 UID에만 허용한다.
- 삭제는 batch delete로 처리하고, 완료 후 두 문서가 모두 존재하지 않는지 재확인한다.

## 상담 종료 후 90일
- 상담 상태/관리 메모는 상담 종료 후 90일 보존 후 정리하는 운영 기준을 적용한다.
- 현재는 무료 범위를 우선하여 Cloud Functions 기반 자동 삭제는 사용하지 않는다.
- 90일 경과 데이터는 관리자 확인 후 수동 정리하는 방식으로 운영한다.
- 자동 정리 기능을 도입하려면 비용·권한·오삭제 위험을 먼저 검토하고 별도 승인한다.

## 세 가지 삭제 흐름
1. 회원이 직접 삭제 요청
   - 관리자 확인 후 관리자 삭제 도구에서 처리
2. 관리자가 운영상 삭제
   - 관리자 삭제 도구에서 2단계 확인 후 처리
3. 상담 종료 후 90일 경과
   - 현재는 관리자 수동 정리
   - 자동 삭제는 미사용

## 관리자 삭제 절차
1. `/admin/delete.html` 접속
2. 허가된 Google 관리자 계정 로그인
3. 삭제 대상 확인
4. 1차 경고 확인
5. 회원 이름 또는 쿠폰번호 재입력
6. `member_requests` + `member_receipts` batch delete
7. 두 문서 미존재 확인
8. 관리자 목록에서 제거 여부 확인

## 권한
- 일반 고객: 삭제 권한 없음
- 관리자: `member_requests`, `member_receipts` 삭제 가능
- 일반 사용자의 임의 삭제는 Firestore Rules에서 차단

## 테스트 원칙
- 실제 고객 데이터로 최초 테스트하지 않는다.
- 테스트 회원만 사용한다.
- 삭제 테스트 후 관리자 목록 및 두 컬렉션 모두에서 제거를 확인한다.

## 현재 상태

- Firestore Rules 관리자 delete 허용 상태
