# 실제 세탁기 세척 과정 사진

기존 공개 작업 기록 3건을 유지하고, 제공받은 원본 작업 영상에서 확인한 세탁기 회전판·필터 세척 장면 2장을 홈페이지에 추가했다. 얼굴·읽을 수 있는 개인정보·현장 식별 정보가 없는 근접 장면만 골랐다. 촬영 장소와 작업 날짜를 추정하지 않았다.

두 사진은 **세척 중**인 장면이다. 동일 현장의 완료 후 결과나 고객의 평가를 확인할 수 없으므로 전후 비교·후기·별점으로 사용하지 않는다. 완료 후 원본과 공개 동의가 확보되면 별도로 검토한다. 원본 영상과 비공개 파일 식별자는 공개 저장소에 올리지 않았다.

사진은 720×1280 WebP이며 합계 69,668바이트다. 원본 프레임 추출 시각과 SHA-256은 `work-process-provenance-20261117.json`에 기록했다. 생성 이미지나 재구성한 장면을 사용하지 않았다.

## 고객 동선

홈페이지의 기존 작업 기록 다음에 ‘세탁기 부품은 이렇게 세척해요’를 배치했다. 기본 접힘 상태의 HTML `details`를 눌러 사진을 확인하고 ‘세탁기 청소 무료 견적 받기’를 누르면 기존 상세 견적의 세탁기 서비스가 선택된다. 새 스크립트를 추가하지 않았으며 이미지에 지연 로딩·비동기 디코딩·고정 크기를 지정했다. 가격과 기존 계산 기준은 바꾸지 않았다.

## 검증

- Firestore 보관기간 에뮬레이터 안에서 Node 검사 163개 통과, 실패·생략 0개. 기존 가격 296개 조합 비교와 신규 갤러리 3개 검사를 포함한다.
- 견적·회원·백업·메일 REST 권한 검사 69개 통과. 별도 데모 에뮬레이터만 사용했다.
- 기존 블로그 사례 동기화 회귀 검사 23개 통과. 자동화 설정과 원본 사례 데이터는 변경하지 않았다.
- 실제 Chrome의 PC 화면에서 사진 2장 표시와 Enter 키 접기·펼치기를 확인했다.
- 390px iframe(스크롤바를 제외한 문서 너비 375px)에서 한 열 배치, 가로 넘침 없음, 사진 표시, 견적 링크 이동과 세탁기 서비스 자동 선택·맞춤 질문을 확인했다. 실물 휴대폰 시험은 수행하지 않았다.
- 운영 반영 결과와 GitHub CI·Pages 실행 링크는 해당 변경 PR에 기록한다. 이 문서의 로컬 검증만으로 운영 배포 성공을 뜻하지 않는다.

이번 검증에서 운영 고객 견적을 새로 제출하거나 고객 데이터를 변경하지 않았다. 기존 Firebase 규칙·인증·관리자·회원가입·쿠폰·알림·유튜브·블로그·Threads 자동화 코드는 변경하지 않았다.

## 백업·복구

변경 전 운영 소스는 `backup/work-photos-before-20261117-badd07f` 브랜치와 커밋 `badd07f467a78c3564f9397603a2a41020aee29d`에 보존했다. 기존 최초 소스 백업과 고객 데이터 암호화 백업도 그대로 유지한다.

복구할 때 전체 main을 과거로 되돌리지 말고 이 변경 커밋을 revert한다. 다른 변경이 섞였다면 `index.html`의 `work-process` 구역과 스타일 버전, `style.css`의 `.process-*`·`.work-process` 규칙, 신규 이미지 2개, 갤러리 검사와 package 검사 목록만 되돌린다. 이후에 들어온 고객 데이터·예약·자동화 변경은 복구 대상이 아니다. 사진은 정적 자산이므로 Firebase 데이터 복원은 필요하지 않다.
