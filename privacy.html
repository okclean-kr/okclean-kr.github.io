개인정보처리방침

1. 수집하는 항목과 목적

오케이청소(이하 '업체')는 회원가입 시 이름, 연락처, 지역, 선택한 무료 서비스, 추천인 코드(초대 링크로 가입한 경우), 이벤트 수신 동의 여부를 받아요. 회원 관리, 쿠폰·포인트 지급, 예약 상담과 작업 진행에만 써요.

2. 수집 방법

회원가입 버튼을 누르면 입력한 이름·연락처·지역·선택 서비스·추천인 코드·이벤트 수신 동의 여부를 Firebase 인증 및 Firestore를 통해 비공개 회원 접수 대장에 저장합니다. 저장 성공이 확인된 경우에만 홈페이지에서 쿠폰번호를 표시합니다. 견적 계산기에 입력한 내용은 이용자 기기에 저장되며, 이용자가 카카오톡이나 문자로 직접 전송한 경우 업체가 받습니다.

3. 보관 기간과 파기

회원 기본정보(이름·연락처·지역·쿠폰·포인트·등급)는 탈퇴 요청 시 또는 마지막 이용 후 2년이 지나면 지체 없이 파기합니다. 상담 진행상태와 관리 메모는 상담이 종료된 날부터 90일이 지나면 삭제 또는 비식별 처리합니다. 법령에 따라 보관해야 하는 거래 기록은 해당 법정 보관기간 동안 별도로 보관할 수 있습니다.

4. 제3자 제공

이용자의 동의 없이 개인정보를 외부에 판매하거나 제3자에게 제공하지 않아요. 회원가입·관리자 기능 운영을 위해 Google Firebase 서비스를 개인정보 저장·처리 수단으로 이용합니다.

5. 이용자의 권리

언제든지 개인정보 열람·수정·삭제와 이벤트 수신 거부를 요청할 수 있습니다. 삭제 요청이 접수되면 본인 확인 후 관리자만 회원 접수정보와 쿠폰 확인정보를 함께 삭제하도록 운영합니다. 아래 연락처로 요청해 주세요.

방문·상담 통계와 수집 선택

방문·상담 통계의 운영 수집이 활성화되면 홈페이지 개선과 유입 채널별 반응 확인을 위해 페이지 조회, 작업 기록 열기, 추천제품 이동, 견적 조작, 카톡·전화·문자 버튼 선택, 신규 가입 저장 완료 같은 행동을 기록합니다. 이 통계에는 행동 종류, 유입 채널 분류, 페이지·서비스 종류, 버튼 위치·상담 경로, 시험 여부, 저장 시각을 담습니다. 별도로 추천제품의 판매처 버튼을 누르면 제품 식별자·유입 채널 분류·저장 시각을 기록합니다. 두 통계 모두 Google Firebase의 Cloud Firestore에 저장하며, 관리자만 조회합니다.

이름·전화번호·상세 주소·상담 본문·원본 URL·쿼리·리퍼러 주소·회원 ID·쿠폰번호·사용자 및 광고 식별자는 서버 통계에 저장하지 않습니다. 실제 통화 내용이나 카톡·문자 메시지 내용도 이 통계 기능으로 수집하지 않습니다.

이 통계 기능은 별도 쿠키를 설정하지 않습니다. 같은 탭의 임시 저장소(sessionStorage)에 출처 분류와 만료 시각을 두고, 다음 페이지에서 30분 이내의 출처 분류만 이어서 참고합니다. 30분은 출처 재사용 기한이며 저장 기록이 그때 자동 삭제된다는 뜻은 아닙니다.

서버 통계 원본의 자동 삭제 기간은 현재 설정되어 있지 않습니다. 아래 수집 끄기는 앞으로 이 브라우저에서 보내는 새 통계를 중지하는 기능이며, 이미 전송된 기록을 삭제하는 기능은 아닙니다. 회원·상담 정보의 보관 기준은 위 3항을 따릅니다.

아래 선택은 방문·상담 통계와 추천제품 판매처 버튼 통계에 함께 적용됩니다. 선택은 이 브라우저의 localStorage에 허용·거부 값 하나로 저장합니다. 회원가입·견적 이용·제품 구매 링크에는 영향을 주지 않습니다. 수집을 다시 켜도 끄기 전에 했던 행동을 다시 전송하지 않습니다.
